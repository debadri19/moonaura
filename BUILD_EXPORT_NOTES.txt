How to use this package (Windows / Laragon)
-------------------------------------------
1. Extract this ZIP into a SEPARATE directory, for example:

       C:\laragon\www\Moonaura_QA

   Do NOT overwrite or replace the existing
   C:\laragon\www\Moonaura folder.

2. Run the non-DB tests first (Laragon terminal):

       php -l tests/newsletter_unsubscribe_tokens.php
       php tests/newsletter_security_fixes.php
       php tests/newsletter_hardening.php
       php tests/newsletter_unsubscribe_tokens.php

   Expected: all PASS, exit code 0. The "multicast is rejected" case and the
   unsubscribe-token cases should pass.

3. Follow QA_WINDOWS_TESTING.md for the safe database/email ordering.
4. See tests/NEWSLETTER_RUNTIME_QA.md for full procedures.
